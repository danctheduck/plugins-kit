• plugins/secrets-kit The plugin implementation these tests exercise.

Test suite for the secrets-kit plugin covering convergence, destination safety, pre-commit guard, repository operations, manifest validation, and cross-process locking

This directory is the pytest suite for the secrets-kit plugin. It exercises convergence, destination safety, the pre-commit guard, repository operations, manifest validation, and cross-process locking. Real age crypto is replaced with a reversible stand-in, and expensive git repositories are built once as templates and copied into private temp paths. That setup lets the tests focus on what the plugin writes, refuses, moves, and recovers rather than on cryptography or git mechanics.

Where to start

Open tests/secrets-kit/conftest.py first: its fleet and fake_age fixtures define the temporary home, git templates, stand-in crypto, and seeded repository that most behavior tests mutate. tests/secrets-kit/test_converge.py is the next stop for the core write, skip, delete, and fail decisions.

Routes

  • Read the harness
    1. tests/secrets-kit/conftest.py fixtures
    2. tests/secrets-kit/sk_testlib.py tree copies
    3. tests/secrets-kit/sk_publish.py publish helpers
  • Trace destination safety
    1. tests/secrets-kit/test_dest_guard.py predicate and commit refusal
    2. tests/secrets-kit/test_destination_leaf.py actual slots and links
    3. tests/secrets-kit/test_destination_ownership.py ownership and collisions
    4. tests/secrets-kit/test_destination_retirement.py moves and durable retirements

Shared fixtures

  • tests/secrets-kit/conftest.py Builds the temporary user home, per-process git templates, fake age, network-free repo, and seeded fleet used across the suite.
  • tests/secrets-kit/sk_testlib.py Copies prebuilt git trees into private temp paths and fails if a copy still points at the template.
  • tests/secrets-kit/sk_publish.py Publishes fixture state either as an ordinary peer commit or through the plugin's owned publication calls.

Convergence decisions

  • tests/secrets-kit/test_converge.py Covers what a convergence pass writes, skips, deletes, locks, and reports, including failure classification and message safety.
  • tests/secrets-kit/test_permission_drift.py Checks matching-content permission repair and no-op hits through the public status and bootstrap consumers.
  • tests/secrets-kit/test_orphan_retry.py Verifies that a failed orphan cleanup preserves the state row and retries after reload.

Destination safety

  • tests/secrets-kit/test_dest_guard.py Pins the exposure predicate, add-time refusal, and output parsing that keep plaintext out of a consumer repository.
  • tests/secrets-kit/test_destination_leaf.py Exercises real destination slots, symlink leaves, parent aliases, and fault injection around lstat and replace.
  • tests/secrets-kit/test_destination_ownership.py Covers collisions, failed new-owner moves, cached selected slots, and ambiguous orphan claims.
  • tests/secrets-kit/test_destination_retirement.py Covers destination moves, handovers, durable retirements, and persisted cleanup retries.

Guard and bootstrap

  • tests/secrets-kit/test_guard.py Drives the real pre-commit hook through real git commits to prove it allows armored blobs and refuses plaintext or leaked keys.
  • tests/secrets-kit/test_init.py Pins seeding safety: remote-first seed detection, refusal when already seeded, and rollback when a seed cannot publish.
  • tests/secrets-kit/test_secrets_bootstrap.py Covers the bootstrap consumer path used by several other tests.

Repository operations

  • tests/secrets-kit/test_operation_lock.py Proves that whole operations contend across independent processes, refuse before protected work, and release after failure or exit.
  • tests/secrets-kit/test_repo.py, tests/secrets-kit/test_repo_binding.py, tests/secrets-kit/test_sync_view.py, and tests/secrets-kit/test_repo_display_cli.py cover repository helpers, clone binding, sync views, and display output.
  • tests/secrets-kit/test_update_metadata.py Covers metadata update behavior.

Manifest and recovery

  • tests/secrets-kit/test_manifest.py Declaration loading, validation, variable expansion, and per-OS destination selection.
  • tests/secrets-kit/test_entry_recovery.py Preserves owned authoring epochs before a clean retry when add, update, or remove faults.
  • tests/secrets-kit/test_seed_recovery.py Covers seed recovery evidence and the recovery record used by entry tests.
  • tests/secrets-kit/test_rotation_recovery.py Covers identity rotation recovery.
  • tests/secrets-kit/test_private_output.py, tests/secrets-kit/test_terminal.py, and tests/secrets-kit/test_perms.py cover private output, terminal handling, and permission checks.
