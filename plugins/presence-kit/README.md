# presence-kit

Presence-kit answers whether the user is at the keyboard, away, or has handed work over, and how Claude should wait, ask and recap in each case.

## Status

Version 0.1.0 is in development. It has no behavior yet: the plugin ships an
empty `hooks/hooks.json` and no skills. Nothing in this plugin runs in a
session.

## Dependencies

Depends on `bootstrap`, which provisions the environment for every plugin in
this marketplace.
