Bootstrap engine and shared library for platform tool installation, Codex CLI integration, environment and config management, code review, and remediation.

bootstrap_lib is the Python package behind the bootstrap plugin. It runs a background SessionStart pass that provisions a machine and provides reusable checks for other plugins. Most modules are check-then-fix pairs that never prompt; work needing elevation is deferred to a remediation queue.

Where to start

plugins/bootstrap/bootstrap_lib/engine.py runs the session pass and wires phases. plugins/bootstrap/bootstrap_lib/config_resolve.py shows how defaults, user, and project config layers merge.

Routes

  • Pass to verdict
    1. plugins/bootstrap/bootstrap_lib/engine.py writes the pending verdict.
    2. plugins/bootstrap/bootstrap_lib/display_relay.py emits it on the next prompt.
  • Deferred install
    1. plugins/bootstrap/bootstrap_lib/apt.py or plugins/bootstrap/bootstrap_lib/brew.py needs elevation.
    2. plugins/bootstrap/bootstrap_lib/fix_queue.py queues it; plugins/bootstrap/bootstrap_lib/fix_runner.py runs it after consent.
  • Config seeding and reads
    1. plugins/bootstrap/bootstrap_lib/config_check.py seeds a plugin config.
    2. plugins/bootstrap/bootstrap_lib/config_resolve.py deep-merges the layers at read time.

Engine and hooks

  • plugins/bootstrap/bootstrap_lib/engine.py -- entry point for the session pass.
  • plugins/bootstrap/bootstrap_lib/proc_lock.py -- serializes concurrent passes.
  • plugins/bootstrap/bootstrap_lib/display_relay.py -- emits the pending verdict.
  • plugins/bootstrap/bootstrap_lib/session_env.py -- buffers environment exports for the pass.

Installing tools

  • plugins/bootstrap/bootstrap_lib/apt.py, plugins/bootstrap/bootstrap_lib/brew.py, and plugins/bootstrap/bootstrap_lib/scoop.py -- package-manager backends.
  • plugins/bootstrap/bootstrap_lib/downloader.py -- fetches and verifies binaries.
  • plugins/bootstrap/bootstrap_lib/tool_check.py and plugins/bootstrap/bootstrap_lib/tool_paths.py -- resolve tools and manage PATH.
  • The per-manager checks -- npm, pypi, venv, python-stub, and git-dependency -- one check per dependency source.

Environment and config

  • plugins/bootstrap/bootstrap_lib/env_manifest.py, plugins/bootstrap/bootstrap_lib/env_features.py, and plugins/bootstrap/bootstrap_lib/env_var_check.py -- env.json layers, features, and variable persistence.
  • plugins/bootstrap/bootstrap_lib/config.py, plugins/bootstrap/bootstrap_lib/config_check.py, and plugins/bootstrap/bootstrap_lib/config_resolve.py -- bootstrap config, plugin config seeding, and layer merge.
  • plugins/bootstrap/bootstrap_lib/path_check.py, plugins/bootstrap/bootstrap_lib/path_prune.py, and plugins/bootstrap/bootstrap_lib/path_repair.py -- add, prune, and repair PATH entries.
  • The manifest merge and linter, OS detection, and the Windows settings probe round out the group.

Codex CLI

  • plugins/bootstrap/bootstrap_lib/codex.py -- detects Codex and builds its exec command.
  • plugins/bootstrap/bootstrap_lib/codex_hook.py -- installs the user-level SessionStart hook.
  • plugins/bootstrap/bootstrap_lib/agent_skills_check.py -- links the Codex agent-skills location to the Claude skills location.

Remediation

  • plugins/bootstrap/bootstrap_lib/fix_queue.py and plugins/bootstrap/bootstrap_lib/fix_runner.py -- queue deferred work and run it after consent.
  • plugins/bootstrap/bootstrap_lib/queue_records.py -- record dedupe and parse helpers.
  • plugins/bootstrap/bootstrap_lib/interrupt_contract.py -- interrupt lifecycle for in-flight work.

Code review

  • plugins/bootstrap/bootstrap_lib/code_review/pipeline.py -- orchestrates a review run.
  • plugins/bootstrap/bootstrap_lib/code_review/review_profiles.py and plugins/bootstrap/bootstrap_lib/code_review/lane_prompts.py -- profiles and lane prompts.
  • plugins/bootstrap/bootstrap_lib/code_review/mechanical and plugins/bootstrap/bootstrap_lib/code_review/mechanical_repository -- single-file and repository-wide checks.
  • plugins/bootstrap/bootstrap_lib/code_review/defaults/review_profiles.yaml and plugins/bootstrap/bootstrap_lib/code_review/defaults/mechanical_checks.yaml -- default profiles and checks.

Shared plumbing

  • plugins/bootstrap/bootstrap_lib/managed_state -- durable machine state: model, runner, CLI, symlinks.
  • plugins/bootstrap/bootstrap_lib/atomic_write.py, plugins/bootstrap/bootstrap_lib/bootstrap_guard.py, and plugins/bootstrap/bootstrap_lib/execution_event.py -- shared write, guard, and event helpers.
  • plugins/bootstrap/bootstrap_lib/subprocess_run.py, plugins/bootstrap/bootstrap_lib/result.py, and plugins/bootstrap/bootstrap_lib/shared_lib.py -- subprocess, Result, and venv sync.
  • Five small single-purpose checks -- font, git-config, ini, json, and link -- one per file format or link.
