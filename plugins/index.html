The plugins-kit marketplace: independently installable Claude Code plugins sharing the bootstrap provisioning engine and the llm-scripting-kit access layer, covering git and Perforce code review, durable job execution, LLM endpoint dispatch, Hue scene sync, PDF rendering, fleet secrets, prompt statusline, cache forensics, markdown auditing, and Unreal Engine automation.

This is the plugins-kit marketplace: independently installable Claude Code plugins, each with its own manifest, documentation, skills, and implementation. A shared provisioning layer puts a user's machine into the state a plugin needs, so consumers rarely run package managers by hand. Deep skill and library areas have separate orientation pages; this page covers the plugin-level surfaces, marketplace rules, and cross-plugin seams.

Where to start

Start with plugins/CLAUDE.md when editing plugin code, because it holds the opinion razor and the register of deliberate non-configurables. For one plugin, open its top-level README first.

Routes

  • Install and provision a plugin
    1. bootstrap run runs the provisioning pass for the current project.
    2. plugins/awesome-kit/bootstrap.json and plugins/awesome-kit/pyproject.toml show what one plugin declares.
  • Audit standards, then review changes
    1. plugins/skills-kit/README.md sets the markdown standards.
    2. plugins/git-kit/README.md reviews git changes against them.
    3. plugins/p4-kit/README.md does the same for Perforce changes.
  • Dispatch model work
    1. plugins/job-kit/README.md declares a model list.
    2. plugins/llm-scripting-kit/README.md resolves the first usable endpoint.
